Требования: Python 3.10 – 3.12, веб-камера.

Шаг 1. Клонируйте репозиторий и перейдите в папку проекта:
    git clone https://github.com/alikhanmatabay/winx-rehab-mvp
    cd winx-rehab-mvp

Шаг 2. Установите зависимости:
    pip install -r requirements.txt

Шаг 3. Запустите приложение:
    streamlit run app.py

После запуска откройте в браузере http://localhost:8501
