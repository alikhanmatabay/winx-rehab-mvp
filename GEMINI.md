## Техническая задача (Кейс SerIQ)
- Оценка одного упражнения — **разгибание локтя (E02)** по загруженному видео или камере.
- Обязательные компоненты: извлечение ключевых точек руки (MediaPipe Pose), собственная ML-модель (классы `complete` / `incomplete` + confidence), сравнение с baseline, разбиение train/val/test строго по ID добровольца, метрики (Balanced Accuracy, F1, матрица ошибок), локальная сводка занятия.
- Интерфейс: двуязычный (**Русский / Қазақша**), крупный шрифт и простые кнопки (адаптировано в том числе для пожилых пациентов).
